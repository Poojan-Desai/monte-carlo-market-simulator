# Monte Carlo Stock Prediction

A Python project that uses Monte Carlo simulation to model stock price trajectories.

## Features
- Fetches historical stock data with `yfinance`
- Runs 1,000+ simulations to project future stock prices
- Visualizes closing prices and simulations with Matplotlib
- Provides statistical insights (mean, median, 5th/95th percentiles)

## Usage
```bash
python stocksim.py
```
